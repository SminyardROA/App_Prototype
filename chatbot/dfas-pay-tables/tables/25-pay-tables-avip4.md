#### **Monthly Navy Aviation Incentive Pay Rates for Officers in Administrative Milestone Billets**

(Effective April 1, 2018)

[DoD FMR Volume 7A Chapter 22](https://comptroller.defense.gov/Portals/45/documents/fmr/current/07a/07a_22.pdf)

|     |     |
| --- | --- |
| **Years of Aviation Service** | **Monthly Rate** |
| **2 or less** | $125 |
| **Over 2** | 156 |
| **Over 3** | 188 |
| **Over 4** | 206 |
| **Over 6** | 650 |
| **Over 10** | 1,000 |
| **Over 22** | 700 |
| **Over 24** | 450 |

**NOTE:**

Administrative milestone billets are designated as department head, commander command, and major command (or equivalent).
